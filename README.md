# Зал и тарелка

Дневник тренировок и питания в виде веб-приложения (PWA) для телефона.

**Открыть и установить:** https://cptnbarbossa.github.io/zal-i-tarelka/

- **iPhone:** Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Samsung / Android:** Samsung Internet → ☰ → «Добавить страницу на» → «Главный экран», или Chrome → ⋮ → «Установить приложение».

Записи хранятся только на устройстве. Резервная копия: вкладка «Цели» → «Сохранить копию».
